# 🎧 שרת הסוכנת הקולית — מדריך הקמה

הסוכנת **שושנה** מתקשרת ללקוחות, קובעת פגישות ומאשרת פגישות קיימות בעברית טבעית.

**איך זה עובד:**
CRM → שרת הסוכנת → **Twilio** מחייג ללקוח → הקול עובר בזמן אמת ל-**Gemini Live** של גוגל → התוצאה חוזרת ל-CRM.

Gemini Live הוא מודל שמדבר בעצמו ולא מקריא טקסט. לכן הוא מבין מה הוא אומר ופונה נכון בזכר ובנקבה.

---

## שלב 1 — מפתח Gemini (2 דקות)
1. נכנסים ל-https://aistudio.google.com/apikey ולוחצים **Create API key**.
2. שומרים את המפתח. הוא נכנס לשדה `GEMINI_API_KEY`.

> אפשר להשתמש באותו מפתח שכבר יש לך בעוזר ה-AI של ה-CRM.

## שלב 2 — הקמת השרת ב-Render (5 דקות)
1. פותחים חשבון ב-https://render.com ומתחברים עם GitHub.
2. **New → Blueprint** → בוחרים את הריפו `am-crm` → Render מוצא את `render.yaml` לבד.
3. ממלאים את המשתנים:

| משתנה | מה זה |
|---|---|
| `GEMINI_API_KEY` | המפתח משלב 1 |
| `TWILIO_ACCOUNT_SID` | משלב 3 (אפשר למלא אחר כך) |
| `TWILIO_AUTH_TOKEN` | משלב 3 |
| `TWILIO_FROM` | המספר שממנו מתקשרים, בפורמט ‎+9725…‎ (שלב 3) |
| `API_TOKEN` | נוצר אוטומטית. זה **קוד הגישה** שמדביקים ב-CRM |

4. אחרי שהשרת עולה מקבלים כתובת, למשל `https://ran-voice-agent.onrender.com`.

> בקובץ מוגדר מסלול **Starter** (בערך 7$ לחודש). מסלול חינמי "נרדם" אחרי 15 דקות בלי שימוש, והשיחה הראשונה אחריו תתעכב בערך דקה.

## שלב 3 — 🎙️ לשמוע אותה לפני שמחברים טלפון
פותחים את `https://<הכתובת-שלך>/test`, מדביקים את קוד הגישה ומדברים איתה דרך המיקרופון.
ככה בודקים את העברית ואת הפנייה בזכר ובנקבה **לפני** שמשלמים על טלפוניה.

## שלב 4 — Twilio (טלפון)
1. פותחים חשבון ב-https://www.twilio.com/try-twilio.
2. **Account SID** ו-**Auth Token** מופיעים בדף הראשי. מדביקים אותם ב-Render.
3. **המספר שהלקוח רואה.** יש שתי אפשרויות:
   - **מומלץ: המספר הנייד שלך.** ב-Twilio נכנסים ל-Phone Numbers → Verified Caller IDs → Add, ומאשרים בקוד שמגיע ב-SMS או בשיחה. הלקוח רואה את המספר שלך ועונה. אם הוא יחזור למספר, הוא יגיע אליך.
   - קונים מספר ב-Twilio (Buy a number). שימו לב שלמספר ישראלי יש דרישות רגולטוריות.
4. ב-**Voice → Settings → Geo Permissions** מסמנים את **Israel**. בלי זה שיחות לישראל ייחסמו.
5. ממלאים את `TWILIO_FROM` ב-Render, בפורמט ‎+972501234567‎.

> בחשבון ניסיון של Twilio אפשר להתקשר רק למספרים מאומתים, ובתחילת כל שיחה מושמעת הודעה באנגלית. לשיחות אמיתיות ללקוחות צריך להטעין יתרה (Upgrade).

## שלב 5 — חיבור ה-CRM
ב-CRM לוחצים 📞 → ⚙️ הגדרות → מדביקים את **כתובת השרת** ואת **קוד הגישה** → **🔌 בדוק חיבור** → **📲 שיחת ניסיון לטלפון שלי**.

---

## הגדרות נוספות (לא חובה)
| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `GEMINI_VOICE` | `Aoede` | הקול. קולות נשיים נוספים: `Kore`, `Leda`, `Zephyr` |
| `GEMINI_MODEL` | בחירה אוטומטית | שם מודל Live מסוים. בלי הגדרה, השרת בוחר בעצמו את המודל העדכני ביותר |
| `MAX_CALL_SECONDS` | `300` | אורך מקסימלי של שיחה |
| `MAX_CONCURRENT` | `3` | מספר שיחות במקביל |

## עלויות (הערכה)
- **Gemini Live:** כמה סנטים לדקת שיחה.
- **Twilio:** לפי מחירון השיחות לישראל (נייד/נייח): https://www.twilio.com/en-us/voice/pricing/il
- **Render:** בערך 7$ לחודש.

## אבטחה
- כל קריאה לשרת דורשת את `API_TOKEN`.
- את העדכונים מ-Twilio השרת מאמת לפי החתימה שלהם.
- הקול של השיחה עצמה עובר בחיבור שאליו מצורף מפתח חד-פעמי לכל שיחה.
- תוצאות שיחות נשמרות בשרת עד 14 יום (ובכל מקרה גם ב-CRM).

## ⚖️ משפטי
- להתקשר רק ללקוחות קיימים. שיחות שיווקיות אוטומטיות בלי הסכמה אסורות (חוק התקשורת, סעיף 30א).
- הסוכנת לא מכחישה שהיא עוזרת דיגיטלית.
- כשלקוח מבקש שלא יתקשרו אליו, הוא מסומן ב-CRM ולא יקבל שיחות נוספות.
